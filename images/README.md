# Images Directory

## Logo File

Please download the Huskynarr logo and save it as `logo.svg` in this directory.

**Download the logo from:** https://huskynarr.de/_nuxt/logo.H2Zu-rsI.svg

You can download it using:
```bash
curl -o images/logo.svg https://huskynarr.de/_nuxt/logo.H2Zu-rsI.svg
```

Or manually download and save it as `images/logo.svg`.

The page will automatically use the local logo if present, otherwise it will fall back to the external URL.
